Knowledge Kompendium

Computable, versioned knowledge. Open specifications and reference implementations.

GitHub Components Principles

A kompendium compounds rather than merely accumulates.

Each contribution is identified, versioned, and attributable, so later work builds on earlier work without guessing what it meant or when it changed. Specifications, reference code, and worked examples live side by side and are released together.

ANF: Analysis Normal Form

A statement-level representation for clinical and terminological assertions, with description-logic semantics for the parts that need them.

Read the ANF documents

Further components will be added as they mature.

Principles

Identity is stable

Every component is addressable by a persistent identifier, independent of its label or location.

Every change is versioned

Status, Time, Author, Module, and Path (STAMP) accompany each assertion.

Semantics where they earn their keep

Description-logic definitions, EL++ and beyond, are first-class. Not every vertex has to carry them.

Specs and code evolve together

Specification text, reference implementations, and examples ship as one release.
